## 修掉两个真实故障（都是用户报错后定位）
1. **用户报“无法创建图形窗口 / single application root window”**：根因是 `_main_impl` 里先用 `ttb.Style().theme_names()` 校验主题名，Style 单例提前绑定根窗口，随后 `ttb.Window(...)` 必然失败。改为 `_offline_theme_names()`（读 `themes.builtin.CURATED_THEMES` + `themes.legacy.STANDARD_THEMES`，不碰 Style）。
2. **WSS 连不上（日志：`create_connection() got an unexpected keyword argument 'proxy'`）**：本机实际是 websockets **13.1**（不是 requirements 里写的 15.0.1），13.x 会把 `proxy=`/`additional_headers` 透传给 `loop.create_connection`。新增 `jusic_core.ws_connect_extras()` 做版本能力探测（14+ 用 additional_headers / 13.x 用 user_agent_header / proxy 仅底层支持才传）。修完 CLI 与主题界面均实测连上房间并播放。

## 用户反馈「没有房间列表」→ 定位并修复（重要陷阱）
- 现象：新版界面左栏房间列表整个不可见。真实 mainloop 下诊断值：`paned sash0=0`、`left pane=1px`、`tree=1x1`。
- 根因：`_build_ui` 里用 `root.after(120, self._set_sash)` 设 `sashpos(0, 400)`，而 120ms 时 paned **还没映射、尺寸仍是 1x1**，Tk 把分栏位置截成 0 → 左栏压成 0 宽。离线手动 `root.update()` 的测试脚本因为时序偏后反而是正常的（所以之前没发现），只有真实 mainloop 会复现。
- 修法：改成 `_maybe_set_sash`，绑在 paned 的 `<Map>`/`<Configure>` 上，等 `winfo_ismapped()` 且 `winfo_width() > 100` 后再设一次（`_sash_done` 保证只设一次，之后尊重用户拖动）；同时给左 Labelframe 设 `width=380` 作为“请求宽度”兜底。
- 顺带加强房间面板：新增 `_rooms_hint_var` 提示行（`_refresh` 显示“正在获取房间列表…”、`_populate` 显示“共 N 个房间 · 双击进入”/“筛选出 x/y 个”/“未获取到房间：请检查网络后点刷新重试”），避免“空列表”被误认为界面坏掉；房间树列宽调整为 150/52/30/100。

## 界面内存对比实测（经典 vs ttkbootstrap 主题版）
- 方法：临时脚本 `%TEMP%\jusic_mem\mem_test.py`（`--console` + `JUSIC_GUI_PYW=1` 防 pythonw 重启，psapi `GetProcessMemoryInfo` 采样，`taskkill /F /T` 清场，含 mpv 内存用 `tasklist` 抓）；另有 `import_probe.py` 测纯导入开销。**不污染仓库**（全在 %TEMP%）。
- 结果（工作集，播放中稳定态，3 次采样一致 ±0.2 MB）：
  | 界面 | python 进程 | 提交 | mpv | 合计 |
  |---|---|---|---|---|
  | `jusic_gui.py`（经典 ttk） | **65.9→66.1 MB** | 40.0 MB | 57.0~57.2 MB | **≈123 MB** |
  | `jusic_gui_bootstrap.py`（litera 主题） | **76.2→76.3 MB** | 49.1 MB | 57.3~57.8 MB | **≈134 MB** |
- 差距 **+10.3 MB（+15.6%）**，来源定位：`import tkinter` 21.3 MB → `import ttkbootstrap` 34.0 MB（**+12.7 MB，且连带 `import PIL`**，Pillow 12.2.0）；再创建 `ttb.Window` 达 52.4 MB；python 空进程基线 18.0 MB。即主题版的增量几乎全在 ttkbootstrap(+Pillow) 的固定开销，而非我们的界面代码。
- 结论：低内存优先用经典版；主题版多约 10 MB（含 mpv 后总差约 8%），可接受。
