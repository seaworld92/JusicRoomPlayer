# 2026-09-10 工作日志

## 新增：下载当前播放歌曲与歌词（jusic_core + jusic_gui）
用户需求：GUI 支持下载当前正在播放的歌曲与歌词。

### 实现
- `jusic_core.py` 新增下载工具：
  - `DownloadCancelled` 异常；`sanitize_filename()`（Windows 非法字符清洗）；`guess_audio_ext(url, source)`（按 URL 路径/音源推断 .mp3/.m4a 等）；
  - `download_file(url, dest, progress, timeout, chunk_size, stop_event)`：urllib 流式下载到 `dest.part` 再 `os.replace` 原子落盘，支持进度回调与取消，失败自动清理临时文件。
- `jusic_gui.py`：
  - 音量行新增 `下载▾` Menubutton（tk.Menu）：下载当前歌曲（音频）/ 下载当前歌词（.lrc）；
  - `_download_song/_download_lyrics` 用 filedialog 让用户选保存位置（预填"歌名 - 歌手"），歌曲扩展名自动判断；
  - `_download_worker` 后台线程下载，进度/完成/失败经 evq 事件（dl-progress/dl-done/dl-error）在 UI 线程更新状态栏与日志；`_downloading` 防重复触发；
  - dispatch 记录 `_current_music` 供下载使用。

### 验证
- 单测：文件名清洗、扩展名推断通过。
- 真实下载：房间当前歌曲《如瓮-石岩》24.4MB 完整下载（Content-Length 一致，进度回调 373 次）；歌词 1261 字节写入成功。
- GUI 集成：mock 保存对话框后 `_download_song`/`_download_lyrics` 均生成正确文件（24.4MB / 1260B，日志含"歌词已保存"）。
- 事件分发单测：状态栏正确显示"下载中… 5.0/10.0 MB（50%）/ 下载完成：song.mp3 / 下载失败：HTTP 403"。
- `.pyw` 已同步；README 功能列表补充"下载▾"。

### 注意
- 网易云下载地址是带时效签名的临时直链，需在歌曲播放时尽快下载；
- dist 中现有 exe/ZIP 不含该功能，发布需重跑 build_exe.bat / build_exe_dir.bat。

## 下载菜单新增"歌曲 + 歌词一起下载"
- `下载▾` 第三项「下载歌曲 + 歌词（一起）」：选一个音频保存路径，歌词自动写为同目录同名 `.lrc`。
- `_download_worker(url, path, kind, lyrics=None)`：下载完成后写歌词（lyrics=(lrc_path,text)）；dl-done 事件改为 3 元组 (path, done, lrc_saved)，进度/完成日志会附带歌词文件名。
- 实测：当前曲《无名之海》音频 42MB + 同名 .lrc 2475B，日志含歌词文件名与"下载完成" ✔；README/`.pyw` 已同步。
